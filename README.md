# Contribution Ledger

A lightweight offline contribution and financial management system built with Flask and SQLite.

## Features

- Member management
- Dues tracking
- Credit and debit ledger
- Running balance calculations
- Search and filtering
- Local SQLite database
- Offline-first deployment

## Technology Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Installation

pip install -r requirements.txt

## Run

run_windows  - If you are on Windows
run_mac_linux.sh - If you are on a mac

Open:

http://127.0.0.1:5000

## Database

The application automatically creates a SQLite database on first run.

Database files are excluded from version control.
